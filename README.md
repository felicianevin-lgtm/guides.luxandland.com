# guides.luxandland.com — Cindy Litzinger guide pages

Static site on GitHub Pages (CNAME guides.luxandland.com). Source of truth = this folder, generated by `_build\build_site_cindy.py` (edit the builder, not the HTML).

| Page | Offer key | FUB tags | FUB plan |
|---|---|---|---|
| /why-didnt-it-sell | guide | luxuryexpired, qrguide | QR: Why Didn't It Sell |
| /the-relaunch-plan | plan | luxuryexpired, qrplan | QR: Relaunch Plan |
| /fall-to-spring-timeline | timeline | luxuryexpired, qrtimeline | QR: Fall-to-Spring Timeline |
| /thinking-about-next-year | nextyear | luxury, qrnextyear | QR: Thinking About Next Year |
| / (contact form) | contact | websitecontact | Website Contact |

`q/` = the postcard QR redirects: `/q/c1` … `/q/c6` → the matching page with `?src=cN` (lands in the FUB note), `/q/home-value` → Cindy's Fello page.
Change a destination by editing that folder's index.html; the printed QR never changes.

Lead capture: `apps-script/Code.gs` runs as a Google Apps Script web app (deploy from felicia@luxandland.com or cindy@luxandland.com; Script Property FUB_API_KEY = Cindy's FUB key).
Its /exec URL goes into `LEAD_ENDPOINT` on every page: `python build_site_cindy.py --endpoint <url>`.
The script creates/merges the FUB person (FUB dedupes on email/phone), tags + stages them, writes a note, and enrolls the plan; the plan's Day-0 email delivers the guide.
